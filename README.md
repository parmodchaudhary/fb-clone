
# 📘 Facebook Clone

A responsive **Facebook Clone** built using modern front-end web technologies. This project was created as a practice project to improve my HTML, CSS, and JavaScript skills by recreating the look and feel of the Facebook web interface.

## 🚀 Features

- 🔐 Login page design
- 🏠 Facebook-style home page
- 👤 User profile section
- 📰 News feed layout
- ❤️ Like, Comment, and Share button UI
- 📷 Stories section
- 💬 Messenger sidebar interface
- 🔍 Search bar
- 🔔 Notification and menu icons
- 📱 Responsive design for desktop and mobile devices
- 🎨 Clean and modern UI inspired by Facebook

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome (Icons)
- Google Fonts

## 🎯 Project Purpose

The primary goal of this project was to gain hands-on experience with front-end web development by recreating one of the world's most popular social media platforms. During development, I focused on:

- Building responsive layouts
- Using Flexbox and CSS Grid
- Organizing reusable components
- Improving UI/UX design skills
- Writing clean and maintainable code
- Practicing JavaScript DOM manipulation
